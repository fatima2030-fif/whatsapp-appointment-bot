# 🤖 WhatsApp Appointment Booking Bot

بوت واتساب ذكي ومحترف مخصص لإدارة وحجز المواعيد تلقائياً وتخزينها في قاعدة بيانات منظمة.

## 🚀 الميزات التقنية للمشروع:
* **Backend:** تم بناء السيرفر باستخدام **Python** وإطار العمل **Flask**.
* **Database:** حفظ البيانات تلقائياً وتحديثها في ملف **CSV** مع نظام ذكي لمنع تكرار البيانات.
* **API Integration:** ربط متكامل مع **Twilio API** لإرسال واستقبال رسائل الواتساب الفورية.
* **Webhooks:** استخدام **ngrok** لإنشاء نفق آمن (Secure Tunnel) لربط السيرفر المحلي.

## 🛠️ التقنيات المستخدمة:
`Python` | `Flask` | `Twilio API` | `ngrok` | `CSV Data Management`
